# UNIT 2: Knowledge Representation & Logic

## Overview
This unit covers knowledge representation schemes, logical reasoning systems, and inference mechanisms in AI.

### Key Topics:
- Propositional Logic: Syntax, Semantics, and Truth Tables
- First-Order Predicate Logic (FOPL): Quantifiers, Inference Rules
- Unification and Resolution Refutation
- Forward Chaining and Backward Chaining
- Structured Knowledge: Semantic Networks, Frames, Conceptual Dependency, and Scripts
