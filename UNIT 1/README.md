# UNIT 1: Introduction to Artificial Intelligence & Problem Solving

## Overview
This unit covers the foundational concepts of Artificial Intelligence, problem formulation, and search strategies.

### Key Topics:
- Introduction to AI, Intelligent Agents, and Environments
- Problem Solving by Searching: State Space Representation
- Uninformed Search Strategies: Breadth-First Search (BFS), Depth-First Search (DFS), Depth-Limited Search
- Informed (Heuristic) Search: Greedy Best-First Search, A* Algorithm
- Constraint Satisfaction Problems (CSP): 8-Queens Problem, Crypt-Arithmetic
- Classic AI Problems: 8-Puzzle, Water Jug, Missionaries & Cannibals, Vacuum Cleaner Agent
