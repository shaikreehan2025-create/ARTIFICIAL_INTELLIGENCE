# UNIT 4: Planning & Machine Learning

## Overview
This unit introduces classical planning techniques, decision making, and fundamental machine learning paradigms.

### Key Topics:
- Planning: STRIPS, Action Representation, Goal Stack Planning
- Partial-Order Planning (POP) and Hierarchical Task Networks (HTN)
- Machine Learning Foundations: Supervised, Unsupervised, and Reinforcement Learning
- Decision Tree Learning (ID3, C4.5)
- Linear Regression, Logistic Regression, and Classification
