# UNIT 3: Reasoning Under Uncertainty & Probabilistic Reasoning

## Overview
This unit explores handling uncertainty, non-monotonic reasoning, and probabilistic models in artificial intelligence.

### Key Topics:
- Quantifying Uncertainty & Acting under Uncertainty
- Basic Probability Notation, Prior and Conditional Probability
- Bayes' Rule and its Applications
- Bayesian Belief Networks: Construction and Exact Inference
- Certainty Factor Theory and Dempster-Shafer Theory
- Fuzzy Logic: Fuzzy Sets, Membership Functions, and Fuzzy Inference
